# Code of Conduct

This project follows the spirit of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Standards

- Be respectful, patient and specific when giving feedback.
- Accept corrections to anatomy and translations without personal criticism.
- Do not post harassment, discrimination, personal data or sexual content. Anatomical terms and images used for teaching are fine.

## Scope

The rules apply in issues, pull requests, discussions and any space that represents the project.

## Enforcement

Maintainers may edit or remove comments, close threads and block accounts that break these rules. Report a problem privately through a GitHub security advisory or by contacting the maintainer (isaac070405) on GitHub. Reports are handled confidentially.
