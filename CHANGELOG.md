# Changelog

All notable changes to this project are listed here, newest first. Dates are in ISO format.

## Unreleased

- Add the Latin language pack (`lang/la/`, Issue #42). Each structure shows its Terminologia Anatomica style Latin name in italics beside the English one (Liver Hepar, Left kidney Ren sinister). `names.js` is generated by `scripts/build_la_pack.js` from the `lang/latin/data/` lists, so the pack and the Word origin add-on share one source. Enable the Latin entry in the language list of every pack and add `'la'` to `PACKS` in `lang/loader.js`. The interface stays English.
- Build Latin names from a direction list (`directions.txt`) and a structure list with gender (`structures.txt`), so a label such as Left kidney or Right superior lobe gets a name even when it is not listed. Sides use full Latin with gender agreement (Ren sinister, Costa V sinistra), and ribs and vertebrae use Roman numerals (Vertebra lumbalis V (L5)). Add `scripts/test_latin_names.js`.
- Name the first two cervical vertebrae Atlas and Axis (`Vertebra C1`, `Vertebra C2`) with their numbered Latin names in brackets.
- Add Latin names for the 1,357 structure labels, shown at the top of the sidebar card.
- Add the Latin and Greek word-origin add-on in `lang/latin/`. It loads after any language pack (`ADDONS` in `lang/loader.js`) and adds a Word origin card to the selection sidebar, for example hepatic = liver related, with 35 roots, 17 prefixes and 23 suffixes. Glosses are English, or Traditional Chinese when that pack is on.

## Milestone: panel layout and view fixes

- Move Anatomical directions under the intro text and the Language switch below Body and Skin tone, and place the model disclaimer at the bottom of the side panel.
- Hide lymphatic vessels, trunks and ducts in organ and airway views. They still show in the lymph, neck and tonsil views.
- Zoom closer to the single alveolar unit by framing only its visible meshes.
- Document that the nasal cavity, oral cavity and pharynx views are cut along the midline on purpose (`known-limitations.html`).

- Replace the GPL-3.0 eye meshes (feelpp/mesh.eye, `eye.glb`) with an eye built in code, remove the eye conversion scripts and the `cadquery-ocp` requirement, and make the whole repository MIT apart from the third-party data in `THIRD_PARTY_NOTICES.md`.
- Use the Blender Studio Realistic base meshes as the male and female skin. They have no skeleton, so capsule bones measured on each mesh feed the existing limb retarget and layered fit.
- Release language pack 1.0.3 and 1.0.2 (same files as 1.0.1) and 1.0.1 (`@isaac070405/anatomy-lang-zh-hant`) with the npm install steps in its README.
- Add the Traditional Chinese (繁體中文) language pack in `lang/zh-Hant/`, a folder that can be copied in or deleted. It puts names beside every structure, group, system and layer, with Chinese search and an on/off button.
- Translate the interface (buttons, headings, descriptions) into Traditional Chinese when the Chinese button is on (`lang/zh-Hant/ui.js`).
- Add a worksheet of interface strings that still need translation (`lang/zh-Hant/worksheet.txt`).
- Add project documents: ACCESSIBILITY, CHANGELOG, CITATION, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY, SUPPORT and THIRD_PARTY_NOTICES.
