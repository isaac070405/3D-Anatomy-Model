# Support

- Questions and ideas: open a GitHub issue or discussion on isaac070405/3D-Anatomy-Model.
- Bugs: open an issue with the browser, the device, the steps and a screenshot.
- Known gaps in the anatomy: read the [known limitations page](https://isaac070405.github.io/3D-Anatomy-Model/known-limitations.html) first.
- How the interface works: see `wiki/Interface.md`.
- Vulnerabilities: follow `SECURITY.md`.

The model is a simplified teaching model and is not medical advice or a clinical tool.
